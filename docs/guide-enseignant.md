# دليل الأستاذ — محاكي تجميع الحاسوب
*Guide de l'enseignant — Simulateur d'assemblage d'un ordinateur*

محاكٍ يتعلّم فيه التلميذ تركيب حاسوب مكتبي خطوة بخطوة: علبة التغذية، اللوحة الأم، البطاقات، الأقراص، والأسلاك. يعمل **دون إنترنت**.

## 1. التثبيت على أجهزة المخبر

| الحالة | ماذا نستعمل |
|---|---|
| Windows 10 / 11، مع صلاحيات المدير | ملف التثبيت `PCBuilderDZ.msi` (*installateur*) |
| Windows 10 / 11، دون صلاحيات أو من قرص USB | الملف `PCBuilderDZ.exe` مباشرة (*version portable*، لا يحتاج تثبيتًا) |
| Windows 7 أو إذا لم يشتغل التطبيق | افتح المجلد `dist` ثم الملف `index.html` بمتصفح Chrome أو Firefox |

- التطبيق يحتاج مكوّن **WebView2** من Microsoft، وهو موجود مسبقًا في Windows 10 و11. إذا ظهرت نافذة فارغة أو رسالة خطأ، استعمل طريقة المجلد `dist`.
- لا حاجة للاتصال بالإنترنت بعد النسخ.

## 2. أوضاع العمل

**الدروس (التعلّم) — *Mode apprentissage***
- 7 دروس بالترتيب: علبة التغذية، اللوحة الأم، البطاقات الداخلية، القرص الصلب، قارئات الأقراص، الأسلاك الداخلية، الأسلاك الخارجية.
- تحت عنوان كل درس: شرح قصير وقائمة القطع بأسمائها بالعربية والفرنسية.
- يسحب التلميذ القطعة من «البساط المضاد للكهرباء الساكنة» (*tapis antistatique*) ويضعها في مكانها. بعض القطع يجب تدويرها حتى تأخذ الاتجاه الصحيح ثم الضغط على «تثبيت».
- خانة **«إظهار التعليمات»**:
  - مفعّلة: تظهر التعليمات والمناطق المضيئة وتلميحات الترتيب — للتعلّم الأول.
  - غير مفعّلة: وضع «الخبير» (*mode expert*) — لا تعليمات، التلميذ يعتمد على معلوماته.
- علامة ✓ تظهر أمام كل درس أكمله التلميذ على هذا الجهاز.

**الاختبار — *Mode test***
- زر «اختبار» أسفل قائمة الدروس.
- يكتب التلميذ اسمه (اختياري) ثم يجمّع الحاسوب كاملًا في 7 مراحل متتالية، **دون تعليمات**، والقطع مخلوطة.
- يُحسب لكل مرحلة: **الوقت** و**عدد الأخطاء** (مكان خاطئ، ترتيب خاطئ، أو الضغط على «تثبيت» والاتجاه غير صحيح).
- في النهاية تظهر ورقة النتيجة، ويمكن **طباعتها** بزر «طباعة النتيجة» (أو حفظها PDF من نافذة الطباعة).

## 3. اقتراح لسير الحصة
1. عرض الدرس على السبورة (جهاز الأستاذ + جهاز العرض) مع تفعيل التعليمات.
2. التلاميذ يعيدون الدرس نفسه على أجهزتهم.
3. إعادة الدرس مع إخفاء التعليمات.
4. في آخر الوحدة: الاختبار وطباعة النتائج أو جمعها.
